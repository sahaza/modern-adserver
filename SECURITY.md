# Security Policy

## Reporting a Vulnerability

Report security vulnerabilities privately via [GitHub private vulnerability reporting](https://github.com/sahaza/modern-adserver/security/advisories/new).

Modern AdServer is derived from Revive Adserver; vulnerabilities inherited from the legacy codebase can also be reported through the [Revive Adserver HackerOne program](https://hackerone.com/revive_adserver).

Do not open public issues for security concerns.
